# Result files

Every CSV in this directory was generated by the author's own scripts in the
parent directory (drivers `run_*.py`, aggregations `analyze_*.py`) from the
author's price snapshots, whose derived statistics are committed under
`data/derived/`; the paper reads its tables from these files and
`papers/check_tables.py` checks every cell against them. `../../../README.md`
indexes them by experiment.
